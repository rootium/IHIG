Lumen, Planet Hopper, and desktop

These are not published as binaries here — an APK is about 26 MB and a desktop build closer to a hundred, which is more than a git repository should carry for something that is one command away from a clone:

git clone https://github.com/rootium/IHIG.git
cd IHIG
tools/build_android.sh games/lumen          # or games/planet-hopper
tools/build.sh games/tessera linux windows  # desktop

The script provisions everything it needs on first run and is safe to re-run. Output lands in build/.
